# DailyDose

> **Polished Concept** — Minimal web app to log your daily coffee drinks, auto-calculate caffeine intake, and show real-time health risk level.

## Core Value

Fast logging + instant feedback on whether your intake is **safe, moderate, high, or dangerous**.

## Key Features

- **Quick log form** — drink type (Espresso, Americano, Latte, Cappuccino, Cold Brew, etc.) + shots/size
- **Auto caffeine calculation** + running daily total
- **Color-coded status:**
  - 🟢 Safe `< 200mg`
  - 🟡 Moderate `200–400mg`
  - 🟠 High `400–600mg`
  - 🔴 Dangerous `> 600mg`
- **Today's summary dashboard**
- **History + basic weekly stats**

---

Super lightweight, mobile-first, daily-use focus.
